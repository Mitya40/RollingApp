# Сведения о сторонних материалах и заимствованиях

## Программные библиотеки

Веб-приложение разработано на платформе .NET 8 с использованием следующих сторонних программных библиотек и фреймворков:

1. Платформа .NET 8 (ASP.NET Core MVC, Entity Framework Core) — лицензия MIT / .NET Foundation.
2. Bootstrap 5 (CSS/JS фреймворк) — лицензия MIT.
3. Chart.js (библиотека визуализации графиков) — лицензия MIT.
4. SheetJS / xlsx.full.min.js (экспорт отчетов в Excel на стороне клиента) — лицензия Apache 2.0.
5. html2pdf.js (экспорт графических отчетов в PDF) — лицензия MIT.

Сведения о лицензиях клиентских библиотек находятся в каталоге проекта `RollingMillApp/wwwroot/lib` рядом с соответствующими файлами.

## Инженерно-справочные материалы и методики

В основу расчетного модуля приложения положены апробированные математические модели и регрессионные зависимости сопротивления деформации, разработанные на кафедре обработки металлов давлением (ОМД) Уральского государственного технического университета (ныне УрФУ).

В коде класса `CalculationContext` реализованы зависимости и коэффициенты, основанные на учебных пособиях и научных публикациях:
1. Смирнов В. К., Шилов В. А., Инатович Ю. В. Калибровка прокатных валков : учебное пособие. М. : Теплотехник, 2008. 490 с.
2. Экспертная система технологии сортовой прокатки / В. А. Шилов, С. П. Куделин, Ю. В. Инатович, А. Р. Бондин // Известия вузов. Черная металлургия. 2015. Т. 58, № 9. С. 710–715.
3. Михайленко А. М., Шварц Д. Л. Конструктивная модель задачи оптимизации сортовой прокатки. Сообщение 1. Геометрия очага деформации // Черные металлы. 2026. № 2. С. 67–74.
