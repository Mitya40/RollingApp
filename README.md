# RollingMillApp

Приложение для автоматизированного проектирования и анализа технологических параметров калибровки простых сортовых профилей.

Программа представляет собой кроссплатформенное веб-приложение, предназначенное для инженеров-технологов прокатных цехов, специалистов проектных институтов и исследователей. Математическое ядро системы базируется на апробированных математических моделях кафедры ОМД УГТУ-УПИ (ныне УрФУ), адаптированных для работы в распределенной многопользовательской веб-среде.

---

## Основная функциональность

### 1. Расчетно-вычислительный модуль
* **Две методики моделирования:**
  * *Метод кафедры ОМД УГТУ* (на основе применения вариационного принципа минимума полной мощности для решения фундаментальной системы уравнений теории пластичности).
  * *Метод соответственной полосы* (эквивалентное приведение деформации сложного сечения в калибре к прямоугольной полосе по Врацкому–Головину).
* **Расчет сопротивления деформации:** поддержка моделей В.И. Зюзина, Л.В. Андреюка – Г.Г. Тюленева, а также расчет с учетом динамического разупрочнения стали.
* **Моделирование температурно-скоростного режима:** поклетевой расчет энергобаланса (лучеиспускание, конвекция, теплопроводность, деформационный разогрев) или использование опытных замеров температур.
* **Учет типа привода:** поддержка индивидуальных приводов клетей и групповых приводов с накоплением и перераспределением крутящего момента двигателя.

### 2. Модуль интерактивной графики и чертежей
* **Векторная визуализация калибров:** отрисовка поперечного сечения калибра, подката и деформируемой полосы в реальном физическом масштабе на холсте HTML5 Canvas.
* **Интерактивный чертеж:** возможность ручной корректировки геометрии калибра (высота, зазор, ширина по врезу, ширина по дну, радиусы закругления, вогнутость) непосредственно в графическом окне с мгновенным перерасчетом площади сечения на клиенте.
* **Автоматическое определение кантовки:** расчет пространственного поворота раската (на 90 или 45 градусов) при переходе между разнородными системами калибров на основе битовых масок.

### 3. Модуль верификации и диагностики
* **Априорная диагностика геометрии:** автоматическая проверка корректности технологической схемы до запуска ресурсоемких расчетов (проверка на переполнение калибров, исключение ситуаций, когда высота после прохода больше или равна высоте подката, а также несовместимость форм подката и калибра).
* **Экспертная оценка ограничений:** пошаговый контроль соблюдения граничных условий по условиям захвата полосы валками, устойчивости полосы против сваливания в калибре, коэффициенту заполнения калибров, запасу прочности валков, редукторов и загрузке двигателей.

### 4. Генерация отчетности
* **Интерактивные графики:** визуализация поклетевого изменения ключевых параметров прокатки с помощью динамических диаграмм.
* **Экспорт в MS Excel:** формирование структурированной книги из 11 листов (титульный лист параметров + 10 вкладок детальных отчетов по каждому технологическому аспекту).
* **Экспорт в PDF:** генерация презентабельного документа формата А4 (альбомная ориентация) со встроенными графиками и таблицами результатов.

## Архитектура и стек технологий

### Backend
* **Платформа:** .NET 8.0, ASP.NET Core MVC.
* **ORM:** Entity Framework Core (подход Code-First).
* **База данных:** SQLite (автономная реляционная СУБД, база хранится в едином файле `DataBase.db` внутри контейнера).
* **Безопасность:** ASP.NET Core Identity (хранение хэшей паролей, RBAC-авторизация).

### Frontend
* **Стилизация и сетка:** Bootstrap 5.
* **Интерактивные элементы:** Native JavaScript (ES6+), AJAX (через Fetch API для работы без перезагрузки страниц).
* **Чертежи и схемы:** HTML5 Canvas API (модуль `blueprintDrawing.js`).
* **Графики:** Chart.js.
* **Экспорт данных:** SheetJS, html2pdf.js.

### Инфраструктура и развертывание
* **Контейнеризация:** Docker (мультиэтапная сборка образов для оптимизации размера).
* **Оркестрация:** Docker Compose.
* **CI/CD:** Скрипты автоматизации развертывания Jenkins (Jenkinsfile).

## Локальный запуск (для разработки)

### Системные требования
* .NET 8.0 SDK или выше.
* Текстовый редактор / IDE (VS Code, Visual Studio 2022, JetBrains Rider).

### Шаги для запуска
1. Клонируйте репозиторий с исходным кодом:
   ```bash
   git clone https://github.com/Mitya40/RollingApp.git
   cd RollingApp
   ```
2. Восстановите NuGet-пакеты:
   ```bash
   dotnet restore
   ```
3. Примените миграции для автоматического создания структуры базы данных SQLite:
   ```bash
   dotnet ef database update
   ```
4. Запустите приложение:
   ```bash
   dotnet run
   ```
Приложение будет доступно в браузере по адресу, указанному в консоли (по умолчанию `https://localhost:5315`).

## Запуск в контейнере (Docker)

Приложение спроектировано для работы в автономном Docker-контейнере, внутри которого уже развернут веб-сервер Kestrel и файл базы данных SQLite.

1. Сборка Docker-образа приложения:
   ```bash
   docker compose build
   ```
2. Запуск контейнера в фоновом режиме:
   ```bash
   docker compose up -d
   ```
Приложение автоматически запустится и начнет прослушивать порт `5315`. Перейдите по адресу `http://localhost:5315`.

## Структура базы данных (SQLite)

* `Mills` (Прокатные станы) — содержит справочные названия и описания станов.
* `Stands` (Клети) — содержит физико-механические, жесткостные и электромеханические параметры каждой клети стана (`DB`, `DSH`, `MU`, `FPOD`, `LKL`, `AKL`, `IR`, `ETA`, `NNOM`, `PDOP`, `MDOP`, `C` и др.).
* `Steels` (Марки сталей) — содержит массив термомеханических коэффициентов `K1`...`K9` и код материала `M` для расчета сопротивления деформации.
* `Profiles` (Профили/Маршруты) — связующая сущность технологической схемы. Поддерживает древовидную связь `ParentProfileId` для хранения истории корректировок.
* `InitialParameters` (Начальные параметры) — параметры заготовки на входе в стан (`W0`, `P0`, `L0`, `T0`, `TAU`, `LR`, `VK`).
* `Passes` (Проходы) — геометрия полосы в каждом проходе (`H0`, `B0`, `H1`, `B1`, `W`, `S`, `BVR`, `BD`, `R`, `ROV`, `R8`, `SUMX`, `PSI`, `Z`, `SP`, `TOP`).
* `AuditLogs` (Журнал аудита) — таблица системного отслеживания действий пользователей. Срабатывает автоматически при вызове `SaveChangesAsync()`, сериализуя измененные сущности в формат JSON.

## Авторизация и разграничение прав (RBAC)

В системе реализована ролевая модель доступа со следующими базовыми ролями:

1. **Оператор (технолог):** имеет доступ к справочникам оборудования и сталей в режиме чтения. Имеет право создавать новые технологические схемы прокатки, редактировать, копировать и рассчитывать **только те профили, создателем которых он является** (контролируется по идентификатору создателя `CreatorId`).
2. **Администратор:** обладает полными правами. Может редактировать паспорта прокатных станов, добавлять/изменять параметры клетей в справочниках, корректировать коэффициенты деформации сталей, а также управлять учетными записями пользователей. Предусмотрена защита от снижения прав последнего администратора в системе.
